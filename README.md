# Tiny Survival

Ein kleines Überlebensspiel im Browser. Du bist auf einer Insel gestrandet und musst 5 Tage überstehen.

## Spielen

Öffne `index.html` im Browser. Eine Installation ist nicht nötig.

## Steuerung

- WASD oder Pfeiltasten: bewegen
- E, Leertaste oder Mausklick: sammeln und Holz ins Feuer legen
- 1: Axt herstellen, 2: Lagerfeuer, 3: Hütte
- F: Beere essen

## Ziel

Sammle Holz, Stein und Beeren. Nachts wird es kalt: Bleib in der Nähe eines Lagerfeuers oder deiner Hütte und achte auf deinen Hunger.

## Technik

HTML, CSS und JavaScript (Canvas), ohne Bibliotheken.
